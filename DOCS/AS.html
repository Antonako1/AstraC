AstraC Assembler

AstraC Assembly is a NASM-like x86 assembly language for the AstraC toolchain. It produces flat binaries with optional ACFH headers.

Assembler Pipeline

StageNameDescription
1PreprocessingHandles directives, macros, includes
2Lexical AnalysisTokenizes into instruction/register/operand tokens
3ParsingBuilds an Abstract Syntax Tree (AST)
4Semantic AnalysisValidates operands, resolves labels and symbols
5OptimizationPeephole optimizations, constant folding
6Code GenerationEmits machine code to output file

CLI Reference

AstraC.exe asm <file.AS> [flags]

Flags:
    arch i386|i286   ; Target architecture (default: i386)
    bits 16|32       ; Force instruction encoding width
    org 7C00         ; Origin address (hex, no 0x prefix)
    exe              ; Emit ACFH executable header
    lib              ; Emit ACFH library header
    entry <label>    ; Entry point label (default: _start)
    warn 0|1|2|err   ; Warning level (err = treat as errors)
    macro <name> <v> ; Define macro for preprocessing
    stepoff 1|2|3    ; Stop after stage (1=preproc, 2=asm, 3=compile)
    verbose          ; Print progress information

Source File Structure

; Comment (stripped by preprocessor)

#include <header.INC>        ; Include another file
#define BUFFER_SIZE 256      ; Define a macro

.data                        ; Mutable data section
msg   DB "Hello", 0          ; Null-terminated string
count DD 0                   ; 32-bit integer

.rodata                      ; Read-only data section
magic DW 0xABCD              ; 16-bit constant

.code                        ; Code section
.use32                       ; 32-bit mode (default)

_start:                      ; Global label
    MOV EAX, 1
    ADD EAX, [count]
    JMP _start

.use16                       ; Switch to 16-bit mode
    MOV AX, BX

Directives

DirectiveDescription
.dataSwitch to the mutable data section
.rodataSwitch to the read-only data section
.codeSwitch to the code (text) section
.use32Set 32-bit code mode (protected mode default)
.use16Set 16-bit code mode (real mode)
.org ADDRSet the origin address (base for label calculations)
.times N db VFill N bytes with value V (supports $ and $$ in expressions)

Section Model

  • .data and .rodata contain only data variable declarations (DB, DW, DD)
  • .code sections contain labels, instructions, and raw numeric literals
  • .use16 / .use32 change operand-size default but do not switch sections

Origin Directive

Sets the base address for offset calculations. Labels and $ references are computed relative to this origin:

.org 0x7C00          ; bootloader loads at 0x7C00

Fill Directive

Emits repeated byte values to pad or fill regions:

.times 510-($-$$) db 0   ; pad to byte 510 (from section start)
0xAA55                    ; boot signature

$ is the current output offset, $$ is the offset of the current section start. The expression $-$$ gives bytes emitted so far in the current section.

Labels

Global Labels

Any identifier followed by a colon defines a global label:

_start:
my_function:
loop_top:

Local Labels (@@)

Scoped to their enclosing global label. Two functions can each define @@done: without collision.

FormSyntaxDescription
Define@@1:Define a numbered local label
Forward@fReference the next local label
Backward@bReference the previous local label
strncopy:
    @@done:              ; scoped as strncopy.@@done
    RET

strncmp:
    @@done:              ; scoped as strncmp.@@done — no collision
    RET

Variable Byte-Size ($variable)

The $ prefix before a variable name evaluates to the byte size of that variable:

.data
msg     DB "Hello, world!", 0
msg_len DD $msg               ; = 14 (bytes in 'msg')

Negative Values

Stored as two's complement:

word_neg  DW -1               ; stored as 0xFFFF
dword_neg DD -100              ; stored as 0xFFFFFF9C

Memory Operands

[EAX]                        ; base register
[EBX + 100]                  ; base + displacement
[ESI + ECX]                  ; base + index

Segment Override

MOV AX, [CS:BX]         ; code segment override (prefix 2Eh)
MOV [ES:DI], AX          ; extra segment override (prefix 26h)

Encoding Reference

Instruction byte stream layout:

[legacy prefix] [segment override] [0F] [opcode] [ModR/M [SIB [disp]]] [immediate]

Encoding Types

  • ENC_DIRECT — Opcode only, no operands (NOP → 90)
  • ENC_REG_OPCODE — Register in low 3 bits of opcode (PUSH EAX → 50)
  • ENC_IMM — Opcode + immediate (INT 0x21 → CD 21)
  • ENC_MODRM — Opcode + ModR/M ± SIB ± disp ± imm

ModR/M Byte

Bits:  7  6 | 5  4  3 | 2  1  0
       mod  |   reg   |   r/m
modMeaning
00Memory, no displacement (except r/m=101 → disp32)
01Memory, 8-bit signed displacement
10Memory, 32-bit displacement
11Register-direct (no memory access)

Prefix Bytes

ByteNamePurpose
66hOperand-size override16-bit ops in 32-bit mode
67hAddress-size override16-bit addressing in 32-bit mode
F2hREPNE / SSE prefixRepeat / SSE hint
F3hREP / REPE / SSE prefixRepeat / SSE hint

Immediate Encoding

  • Opcodes 83h and 6Bh always use 8-bit sign-extended immediates
  • All immediates are little-endian
