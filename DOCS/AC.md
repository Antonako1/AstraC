# AC - AstraC language

AC (AstraC) is a lightweight programming language designed for low-level system programming, particularly for the x86 architecture. It provides a simple, C-like syntax while allowing direct access to hardware and system resources. AC is intended for use in environments where performance and control over the hardware are critical, such as operating system development, embedded systems, and low-level applications.
