AstraC Compiler & Language Reference

AstraC is a lightweight C-like systems programming language and compiler for i386 and i286 x86 architectures. It produces standalone raw binary files with no object-linking step. The language is case-insensitive and designed for low-level work — operating systems, bootloaders, embedded firmware, and bare-metal applications.

Compiler CLI

AstraC.exe comp <file.AC> [flags]

Flags:
    --arch i386|i286   ; Target architecture (default: i386)
    --bits 16|32       ; Code mode (default: 32)
    --entry <label>    ; Override entry point (default: main)
    -E                 ; Stop after preprocessing (emit .AC)
    -S                 ; Stop after codegen (emit .AS)
    --stepoff <1|2|3>  ; Stop after given stage
    --verbose          ; Print progress information
    --warn 0|1|2|err   ; Warning level (err = treat as errors)
    --org <addr>       ; Origin address (hex, no 0x prefix)
    macro <name> <v>   ; Define preprocessor macro

Pipeline Stages

StageDescriptionStop Flag
1. PreprocessingHandle #include, #define, #if/#else/#endif-E / stepoff 1
2. Lexical AnalysisTokenize into keywords, identifiers, literals, operators—
3. ParsingBuild Abstract Syntax Tree (AST) from token stream—
4. VerificationSemantic checks — types, scopes, forward declarations—
5. Code GenerationEmit .AS assembly source-S / stepoff 2
6. AssemblyAssemble .AS → flat .BIN binarystepoff 3

Output Files

input.AC → [Preprocessor] → /TMP/00.AC → [Compiler] → input.AS → [Assembler] → input.BIN
  • With -E: outputs preprocessed source to /TMP/00.AC
  • With -S: outputs assembly source to input.AS
  • Default: outputs binary to input.BIN

Identifiers and Keywords

The language is case-insensitive — all identifiers and keywords are normalized to UPPER CASE during lexing. MyVar, myvar, and MYVAR are the same identifier.

Explicit Casting

C-style cast syntax: (type)expression. No runtime validation.

U32 x = (U32)ptr;           // pointer → integer
PU8  p = (PU8)0xB8000;      // integer → pointer
U8   b = (U8)x;             // narrowing cast

    if (local_var > 0) {
        U32 block_var;       // block-scoped (C99-style)
    }
}

Scope Rules

  • Block scope: Variables declared inside { } are scoped to that block.
  • Loop variables: for (U32 i = 0; ...) — i is scoped to the loop body only.
  • Function scope: Labels (goto label:) are scoped to the defining function.
  • Forward declarations: Functions must have a prototype before first use.

typedef

typedef U32   COUNTER;
typedef PU8   STRING;
typedef struct _POINT { U32 x; U32 y; } POINT, *PPOINT;

Variables and Storage

Global Variables

Placed in .data (mutable) or .rodata (read-only). Default to zero if no initializer is provided. There is no .bss section.

static U32 counter = 0;         // .data, explicit zero
local  PU8 msg     = "Hello";   // .data, pointer to .rodata string

Stack Variables

Function-local and block-local variables live on the stack. Aggregate initialization is not supported — initialize field-by-field:

U32 arr[256];
for (U32 i = 0; i < 256; i++) {
    arr[i] = i;
}

Stack Arrays

U32 buf[256];               // stack array of 256 U32s
PU8 names[10];              // array of 10 pointers

Structs, Unions, and Enums

Structs

typedef struct _STUDENT {
    U32 id;
    PU8 name;

U32 main() {

    s.id   = 12345;          // field-by-field init only
    s.name = "John";
    PPOINT p = &s;
    p->id = 0;              // auto-dereference

Functions

Declaration and ABI

RETURN_TYPE name(PARAM_TYPE p1, PARAM_TYPE p2, ...);

cdecl ABI: Arguments pushed right-to-left. Return in EAX. Caller cleans the stack. Every function gets PUSH EBP; MOV EBP, ESP.

Entry Point

Default: U32 main(U32 argc, PPU8 argv). Override with --entry flag.

Function Pointers

typedef U32 (*BINOP)(U32, U32);

U32 apply(BINOP op, U32 a, U32 b) {
    return op(a, b);                   // call through pointer
}

Void Functions

Either U0 foo() or VOID foo(). Use return; with no value.

Variadic Functions

U32 sum(U32 count, ...) {
    va_list args;
    va_start(args, count);
    U32 total = 0;
    for (U32 i = 0; i < count; i++) {
        total += va_arg(args, U32);
    }
    va_end(args);
    return total;
}

Assembly Block

U32 main() {
    U32 result;
    asm {
        mov eax, 5
        add eax, 10
        mov result, eax
    }
    return result;
}
  • The asm block is literally pasted into .AS output — no validation.
  • Outer-scope variables are translated to [EBP+offset]/[EBP-offset].
  • Struct member access (student.id) is translated to correct EBP offset.
  • Clobber-everything barrier: all registers assumed destroyed.
  • Any valid assembler syntax including labels and raw opcodes is permitted.

Code Generation

Memory Layout

SectionContent
.dataMutable globals — initialized or default-zero
.rodataRead-only data — string literals
.codeAll generated instructions

No .bss section. Uninitialized globals default to zero in .data.

Calling Convention Details

  • Arguments pushed right-to-left
  • CALL pushes return address
  • PUSH EBP; MOV EBP, ESP prologue on every function
  • Local variables at [EBP-N], parameters at [EBP+8+4*N]
  • Return value in EAX
  • Caller cleans stack with ADD ESP, N
  • All 32-bit pointers, 4-byte stack alignment

External Dependencies

The compiler does not provide any runtime library. Functions like MEMZERO, MEMSET, memcpy must be implemented by the developer or linked from an external runtime.

Complete Example

#include "stdlib.ah"

typedef struct _STUDENT {
    U32 id;
    PU8 name;
} STUDENT, *PSTUDENT;

PU8 get_student_name(PSTUDENT student) {
    return student->name;
}

U32 main(U32 argc, PPU8 argv) {
    STUDENT student;
    student.id   = 12345;
    student.name = "John Doe";

    if (student.id > 10000) {
        for (U32 i = 0; i < 5; i++) {
            asm {
                mov eax, student.id
                add eax, i
                mov student.id, eax
            }
        }
    }

    switch (student.id) {
        case 0:  return 0;
        case 50: return 50;
        default: break;
    }

    PU8 name = get_student_name(&student);
    return student.id;
}
